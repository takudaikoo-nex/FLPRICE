# 機能提案・デザイン改善ロードマップ

> 対象: 葬儀プラン見積りアプリ（ユーザー画面 / 管理画面）
> 作成日: 2026-04-04

---

## A. ビジュアル・UX 改善

### A-1. アイテム画像ギャラリー ⭐ 最優先

**課題**: 棺・祭壇・骨壷・供花などグレード選択時に、テキスト名称だけでは顧客が判断できない

**提案**:
- ドロップダウン選択肢にサムネイル画像を表示
- 選択時にプレビューを拡大表示（現在のDetailModalを拡張）
- 管理画面で画像アップロード（Supabase Storage連携）

**対象アイテム**:
| アイテム | 画像数目安 |
|---|---|
| お棺アップグレード（9種） | 各1-2枚 |
| 祭壇（5種） | 各2-3枚（正面・サイド） |
| 骨壷アップグレード（3種） | 各1枚 |
| 供花（3種） | 各1枚 |
| 遺影写真フレーム（2種） | 各1枚 |

**UI案**:
```
┌──────────────────────────────────────────┐
│ 祭壇を選択                               │
├──────────────────────────────────────────┤
│ ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐        │
│ │     │ │     │ │     │ │     │ ...     │
│ │ IMG │ │ IMG │ │ IMG │ │ IMG │        │
│ │     │ │     │ │     │ │     │        │
│ └─────┘ └─────┘ └─────┘ └─────┘        │
│  FO-01   FO-33   FO-14   FO-18         │
│ ¥100,000 ¥200,000 ¥250,000 ¥500,000    │
│  [選択中]                                │
└──────────────────────────────────────────┘
```

### A-2. プラン選択画面のビジュアル刷新

**課題**: 現在のプランカードは情報密度が低く、価格とテキストのみ。顧客対面時に「どう違うの？」が伝わりにくい

**提案**:

#### a) プランカードにアイコン・イラスト追加
- 各プランにシンボルアイコン（棺のみ / 花 / 家 / 祭壇1日 / 祭壇2日）
- カード上部にイラスト or アイコンエリアを追加

#### b) プラン比較バー
- 「含まれるもの」をアイコンドットで横並び表示
- 上位プランほどドットが増える → 視覚的に差が分かる

```
シンプル直葬    ●●●○○○○○○○   ¥150,000
お別れ火葬式    ●●●●●●○○○○   ¥275,000
お別れ自宅葬    ●●●●●●●○○○   ¥400,000
一日葬          ●●●●●●●●●○   ¥500,000
二日葬          ●●●●●●●●●●   ¥700,000
```

#### c) カテゴリタブのビジュアル強化
- 現在のフラットタブ → カード型タブに変更
- 火葬式: オレンジ系グラデ + 炎アイコン
- 葬儀: エメラルド系グラデ + 花アイコン
- 選択時のアニメーション追加（スライドイン）

---

### A-3. 見積サマリーの視覚化

**課題**: 現在は合計金額のみ表示。内訳が見えず、何がいくらか顧客に説明しにくい

**提案**:

#### a) リアルタイム内訳パネル
- フッター上にスライドアップする内訳パネル
- プラン基本料 + 各オプション金額をリスト表示
- 税込/税抜の切り替えトグル

```
┌─── お見積り内訳 ──────────────────────┐
│ 二日葬プラン（基本）      ¥700,000    │
│ ├ お棺アップグレード      ¥ 37,450    │
│ ├ 祭壇 FO-33             ¥200,000    │
│ ├ 火葬料金                ¥ 75,000    │
│ └ 斎場料金                ¥150,000    │
│───────────────────────────────────────│
│ 小計（税抜）           ¥1,162,450    │
│ 消費税（10%）            ¥ 98,745    │
│ 非課税分                 ¥225,000    │
│━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━│
│ 合計                  ¥1,486,195    │
└───────────────────────────────────────┘
```

#### b) 円グラフ / 棒グラフ表示
- プラン基本料 vs オプション の比率を可視化
- 「基本プランだけでこれだけカバーされます」の安心感

---

### A-4. カラーテーマ・トーンの統一

**課題**: 現在エメラルド + パープルの2テーマだが、葬儀サービスとしてはやや明るすぎる箇所がある

**提案**:
- **メインカラー**: 落ち着いたネイビー or ダークグリーン（信頼感）
- **アクセント**: ゴールド系（品格）
- **背景**: 温かみのあるウォームグレー（冷たさ回避）
- **プラン別**: 淡いグラデーションで差別化（寒色→暖色で価格帯を表現）

```
カラーパレット案:
- Primary:    #2C4A3E (深緑)
- Secondary:  #B8860B (落ち着いたゴールド)
- Background: #F7F5F2 (ウォームグレー)
- Surface:    #FFFFFF
- Text:       #1A1A1A
- Muted:      #6B7280
```

---

### A-5. タイポグラフィ改善

**課題**: Zen Maru Gothic は柔らかすぎる場面がある（価格・ビジネス文書）

**提案**:
- **見出し・UI**: Zen Maru Gothic を維持（親しみやすさ）
- **価格表示**: Noto Sans JP の Mono/Bold に変更（数字の視認性）
- **印刷文書**: 游明朝のまま維持（フォーマル）

---

### A-6. モバイル画面のUX改善

**課題**: スマホ対応はされているが、対面接客時にスタッフがタブレットで使うケースが多いはず

**提案**:
- **タブレット最適化レイアウト**（768px-1024px）を追加
- **スワイプでプラン切替**（左右フリック）
- **ピンチズームで画像拡大**（祭壇・棺の画像閲覧時）
- **横画面モード**対応（タブレットを顧客に見せる場面）

## B. 機能追加

### B-1. PDF出力の改善

**課題**: 現在はブラウザ印刷依存。レイアウト崩れ・環境差がある

**提案**:
- サーバーサイド or クライアントサイドPDF生成（react-pdf / jspdf）
- A4固定レイアウト
- メール添付可能な形式
- 会社ロゴ・印鑑の埋め込み
- 複数ページ対応（オプション多い場合）

---

### B-2. 見積履歴・検索

**課題**: 現在は番号直接入力でしか呼び出せない

**提案**:
- 故人名・申込者名でのテキスト検索
- 日付範囲フィルタ
- プラン種別フィルタ
- 金額帯フィルタ
- リスト表示 + カード表示の切替
- 最近使用した見積をクイックアクセス

```
┌─ 見積履歴 ─────────────────────────────────────┐
│ 🔍 [検索...          ] [2026/03 ▼] [全プラン ▼]│
│                                                 │
│ #000125  山田太郎 様  二日葬  ¥1,200,000  3/28 │
│ #000124  佐藤花子 様  一日葬    ¥780,000  3/25 │
│ #000123  田中一郎 様  直葬      ¥185,000  3/22 │
│ ...                                             │
└─────────────────────────────────────────────────┘
```

### B-3. 見積比較モード

**課題**: 「直葬とお別れ火葬式で迷っている」→ 現状は手動で切替えて確認

**提案**:
- 2プランを左右に並べて比較表示
- 含まれるもの / オプション差分をハイライト
- 合計金額差を大きく表示
- 「このプランにはこれが追加されます」を明示

```
┌────────────────┐  ┌────────────────┐
│ シンプル直葬    │  │ お別れ火葬式    │
│ ¥150,000       │  │ ¥275,000       │
│                │  │                │
│ ✓ 搬送(20km)  │  │ ✓ 搬送(50km)  │
│ ✗ 安置        │  │ ✓ 安置        │
│ ✗ 枕飾り      │  │ ✓ 枕飾り      │
│ ...            │  │ ...            │
│────────────────│  │────────────────│
│                │  │ +¥125,000      │
└────────────────┘  └────────────────┘
```

### B-4. 見積の複製・バリエーション作成

**課題**: 「オプション追加した場合としない場合の両方見たい」に対応できない

**提案**:
- 既存見積を「複製して編集」ボタン
- 差分表示（元の見積との価格差）
- 複数バリエーションを保存 → 顧客に複数案提示

---

### B-5. 顧客向け共有リンク（将来）

**課題**: 遠方の親族と相談したい場合、電話で金額を伝えるしかない

**提案**:
- 見積内容を読み取り専用URLで共有
- URLにトークン付与（有効期限付き）
- QRコード生成（紙で渡す場面）
- 閲覧専用のシンプルなビュー

---

### B-6. お気に入り / テンプレート機能

**課題**: よくある構成を毎回ゼロから組み立てている

**提案**:
- 「よくある構成」をテンプレートとして保存
- 例: 「二日葬 + 祭壇FO-33 + 供花YW-2」= テンプレA
- ワンクリックで読み込み → 顧客情報だけ入力
- 管理画面からテンプレート管理

---

### B-7. 売上ダッシュボード（管理画面）

**提案**:
- 月別見積件数・金額の推移グラフ
- プラン別の選択率（円グラフ）
- よく選ばれるオプションランキング
- 平均見積金額の推移

---

### B-8. オプション推薦 / アップセル表示

**提案**:
- プラン選択後「このプランでよく選ばれています」バッジ
- 追加率の高いオプションを上位に自動ソート
- 「あと¥XX,XXXで〇〇プランにアップグレードできます」の案内
